# FoodTrack DB 🚚

Base de datos relacional para un sistema de food trucks, desarrollada en SQL como proyecto del Data Science Bootcamp de Henry.

## De qué trata

El proyecto modela la información de un sistema de food trucks en una base de datos relacional: diseño de tablas, relaciones entre ellas y carga de datos, para poder consultar la información y responder preguntas de negocio con SQL.

## Qué incluye

- **`scripts/`**: scripts SQL del proyecto.
- **`data/`**: datos utilizados para poblar la base.

## Qué practiqué en este proyecto

- Diseño de un modelo relacional con claves primarias y foráneas.
- Creación de tablas y carga de datos.
- Consultas SQL para analizar la información: uniones entre tablas, agrupaciones y agregaciones.
